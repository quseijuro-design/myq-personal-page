# Personal Expression Page

一个用 Esther Design System 风格制作的个人页面。

主题是“表达的入口”：把说不顺的话、散落的标签和复杂资料，整理成可以表达、可以学习、可以继续探索的东西。

## Files

- `index.html` - 主页面
- `assets/avatar.png` - 页面头像
- `assets/my-humation-avatar.svg` - Humation 头像版本
- `assets/my-humation-avatar.html` - Humation 头像预览
